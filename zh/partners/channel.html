渠道合作 ​

Tokeness 支持 API + Key 的标准分销接入方式，适合已有开发者、企业客户或聚合平台资源的合作伙伴。

合作模式 ​

项目说明
接入方式API + Key 标准模式
系统兼容兼容 New API 聚合系统
账户能力分销账户功能与平台个人用户一致
结算方式先付费，客户调用消耗从账户余额实时扣除
服务支持1 对 1 商务对接，技术问题由工程师协助处理

准入政策 ​

根据本地邮件材料，当前渠道政策包括：

项目当前说明
保证金无保证金
最低起充无最低起充额度
余额充值余额长期有效
扶持首批优质分销商可沟通首单充值扶持

阶梯折扣 ​

渠道合作伙伴可按月流水获得阶梯折扣。现有报价表中的示例结构：

月流水合作折扣
1 万 < 流水 < 5 万95 折
5 万 ≤ 流水 < 10 万9 折
流水 ≥ 10 万8.5 折

官转渠道不参与合作伙伴折扣；最终政策以正式商务确认为准。

对接资料 ​

渠道伙伴通常需要：

  1. 渠道报价表。
  2. 公司宣传彩页。
  3. 合作协议或合同模板。
  4. API 接入说明。
  5. 客服和技术支持入口。

本仓库已包含渠道宣传材料和合同模板，可按实际商务流程分发。

联系方式 ​

邮箱：contact@tokeness.io

商务沟通可按现有邮件材料中的方式进一步对接。
