控制台概览 ​

Tokeness 控制台用于管理模型、Key、日志和余额。登录后默认进入概览页。

导航结构 ​

控制台当前主要入口如下：

分组页面用途
聊天游乐场测试模型返回
聊天聊天在网页内直接对话
常规概览查看账户和调用的概览信息
常规模型广场查看可用模型并复制模型名
常规数据看板查看模型、调用与消费相关数据
常规API 密钥创建和管理接口调用 Key
常规使用日志排查请求、模型、状态和费用
个人钱包充值、余额和账务入口
个人个人资料管理账号信息

操作顺序 ​

  1. 在“钱包”完成充值。
  2. 在“API 密钥”为项目创建独立 Key。
  3. 在“模型广场”确认需要调用的模型名称。
  4. 在客户端或代码中配置 https://n.tokeness.dev/v1。
  5. 在“使用日志”和“数据看板”查看调用是否成功。

搜索与排查 ​

顶部搜索可定位功能入口。调用失败时，按下面顺序排查：

检查项说明
Key是否复制完整，是否被禁用或额度耗尽
余额钱包余额是否足够覆盖本次调用
模型模型名称是否正确，当前分组是否支持
请求格式是否使用 OpenAI 兼容格式和正确 Base URL
日志使用日志中是否有状态码、错误原因或上游返回

用量日志中可观察的字段 ​

排查单次请求时，以页面实际展示为准。当前文档可确认的观察项包括：

字段用途
状态码判断请求是否成功或属于 4xx/5xx
错误原因定位鉴权、额度、格式或上游返回的问题
模型确认请求使用的模型名称
费用对照本次请求的消耗

页面没有展示的字段不要自行推断；排查时同时记录请求时间、路径和客户端错误信息。
