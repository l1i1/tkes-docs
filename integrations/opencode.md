# OpenCode

OpenCode can use Tokeness through OpenAI-compatible provider configuration.

## Configuration

```txt
Base URL: https://n.tokeness.io/v1
API Key: your Tokeness API key
Model: exact model name copied from Tokeness
```

Keep the API key in local configuration or environment variables that are not committed. After one test prompt, check Tokeness usage logs to confirm the request and model routing.
