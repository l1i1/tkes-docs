# Dify

Dify can connect to Tokeness through OpenAI-compatible model provider settings.

## Steps

1. Open Dify model provider settings.
2. Add an OpenAI-compatible provider.
3. Set Base URL to `https://n.tokeness.io/v1`.
4. Paste the Tokeness API key.
5. Add model names copied from the Tokeness console.
6. Test the provider before using it in an application workflow.

If Dify validates the provider but app calls fail, check the model selected inside the app workflow.
