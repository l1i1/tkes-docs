# VS Code + Claude Code

When using Claude Code from VS Code, configure the underlying provider, switcher, or proxy to use Tokeness.

## Checklist

- Base URL: `https://n.tokeness.io/v1`
- API key: Tokeness API key stored outside the repository
- Model: exact model name from the Tokeness console
- Provider type: OpenAI-compatible or the compatible route required by your tool

After configuration, run one small request and confirm it appears in Tokeness usage logs.
