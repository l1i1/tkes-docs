# Cursor

If your Cursor setup supports custom OpenAI-compatible providers, configure it with Tokeness.

## Configuration

```txt
Base URL: https://n.tokeness.io/v1
API Key: your Tokeness API key
Model: exact model name copied from Tokeness
```

Keep real keys out of shared settings files. If Cursor reports authentication or model errors, verify the key, balance, model name, and Base URL.
