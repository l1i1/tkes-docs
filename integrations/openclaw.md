# OpenClaw

OpenClaw can connect to Tokeness when its provider settings support a custom OpenAI-compatible endpoint.

## Configuration

```txt
Provider: OpenAI Compatible or custom OpenAI
Base URL: https://n.tokeness.io/v1
API Key: your Tokeness API key
Model: exact model name copied from Tokeness
```

If the first request fails, check provider type, model name, balance, key quota, and usage logs.
