# LibreChat

LibreChat can route requests to Tokeness when configured with an OpenAI-compatible endpoint.

## Configuration Values

```txt
Base URL: https://n.tokeness.io/v1
API Key: your Tokeness API key
Model: exact model name copied from Tokeness
```

Use LibreChat's environment or provider configuration files according to your deployment. Do not commit real keys.

After deployment, send a short message and verify the request appears in Tokeness usage logs.
