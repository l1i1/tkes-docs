# Open WebUI

Open WebUI can connect to Tokeness through OpenAI-compatible endpoint settings.

## Configuration

```txt
OpenAI API Base URL: https://n.tokeness.io/v1
OpenAI API Key: your Tokeness API key
Model: exact model name copied from Tokeness
```

Restart or reload Open WebUI after changing environment variables. Then send a short prompt and check Tokeness usage logs.
