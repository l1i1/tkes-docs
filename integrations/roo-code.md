# Roo Code

Roo Code can connect to Tokeness through OpenAI-compatible provider settings.

## Configuration

| Field | Value |
| --- | --- |
| Provider | OpenAI Compatible or custom OpenAI |
| Base URL | `https://n.tokeness.io/v1` |
| API Key | Tokeness API key |
| Model | Exact model name copied from Tokeness |

Run a small test request and review Tokeness usage logs if the tool reports an error.
