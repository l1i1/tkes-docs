# Cherry Studio

Cherry Studio can connect to Tokeness through a custom OpenAI-compatible provider.

## Steps

1. Open Cherry Studio provider settings.
2. Add a custom provider or OpenAI-compatible provider.
3. Set Base URL to `https://n.tokeness.io/v1`.
4. Paste your Tokeness API key.
5. Add or select a model name copied from the Tokeness console.
6. Save and send a short test message.

If authentication fails, confirm the key is enabled and the Base URL includes `/v1`.
