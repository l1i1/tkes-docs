# Cline

Cline can use Tokeness through an OpenAI-compatible or custom provider configuration.

## Steps

1. Open Cline provider settings.
2. Choose OpenAI Compatible or a custom provider option.
3. Set Base URL to `https://n.tokeness.io/v1`.
4. Paste your Tokeness API key.
5. Enter a model name copied from Tokeness.
6. Save and send a short test request.

If a request fails, check provider type, Base URL, key quota, balance, and model name.
