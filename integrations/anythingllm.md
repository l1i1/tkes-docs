# AnythingLLM

AnythingLLM can use Tokeness through OpenAI-compatible provider settings.

## Steps

1. Open LLM provider settings.
2. Select OpenAI or OpenAI Compatible if available.
3. Set Base URL to `https://n.tokeness.io/v1`.
4. Paste your Tokeness API key.
5. Enter a model name copied from Tokeness.
6. Run a test chat and review Tokeness usage logs.

For workspace-specific models, confirm the workspace is using the Tokeness provider you configured.
