# Channel Partners

Tokeness supports channel cooperation for communities, software vendors, agencies, and service providers that help users adopt AI APIs.

## Suitable Partners

- AI tool communities and tutorial creators.
- Software vendors integrating an OpenAI-compatible API gateway.
- Agencies helping customers deploy AI workflows.
- Teams that need consolidated model access and billing.

## Cooperation Topics

- Integration guides and onboarding materials.
- Referral or channel cooperation.
- Customer support workflow.
- Model and quota planning.
